The dots are the tasks

Each dot is one task the agent holds. Tasks fill from the centre outward, oldest at the centre, the way a kolam is drawn. The line reaches a dot only when its task is done, so a finished kolam is a finished queue and bare dots are work still owed.

Hover a dot for the task, or tab to it. Click it to open the proposal. Hover the line for the agent and its three words. Nothing here writes.

  • Queued — a ring: held, not moving
  • Being built — pulsing: in hand now
  • Done — filled: the line reaches it
  • Blocked — amber: somebody else has to move
  • Open ground — faint: no task on this dot
